# Lingkungan Eksekusi (Runtime) NUSANTARA

Folder ini dicadangkan untuk lapisan *runtime environment* bahasa NUSANTARA.

---

## Cakupan Masa Depan

- Manajemen alokasi dan dealokasi memori dinamis.
- Pengumpul sampah memori (*Garbage Collector*) atau model kepemilikan memori presisi (*ownership/RAII*).
- Lapisan abstraksi sistem operasi (I/O, berkas, soket jaringan, benang pemrosesan/*threads*).
- Mesin penjadwal konkurensi asinkron (*scheduler/event loop*).
