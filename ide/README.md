# Lingkungan Pengembangan Terintegrasi (IDE) & Ekstensi Editor

Folder ini dicadangkan untuk integrasi penyunting kode bagi pengembang bahasa NUSANTARA yang akan dikembangkan pada **Phase 31 dan 32**.

---

## Rencana Integrasi

1. **Ekstensi VS Code (Phase 31):**
   - Penyorotan sintaksis (*syntax highlighting*) untuk berkas `.nusantara`.
   - Konfigurasi *Language Server Protocol* (LSP) untuk pelengkapan otomatis (*auto-complete*), intellisense, dan inspeksi tipe data.
   - Pemicu pemformatan berkas saat disimpan (*format on save*).
2. **NUSANTARA IDE Mandiri (Phase 32):**
   - Lingkungan pemrograman mandiri berbahasa Indonesia untuk pendidikan dan industri.
