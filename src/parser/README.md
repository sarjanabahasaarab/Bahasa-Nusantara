# Modul Parser NUSANTARA (Phase 7 Rencana)

Direktori ini dipersiapkan untuk implementasi **Penganalisis Sintaksis (Parser)** pada **Phase 7**.

---

## Batasan Phase 6:
Sesuai rancangan arsitektur berjenjang, pada Phase 6 **hanya modul Lexer** (`src/lexer/`) yang diimplementasikan.
Komponen Parser akan dibangun pada Phase 7 untuk membaca `TokenStream` dari Lexer dan menyusunnya menjadi Pohon Sintaksis Abstrak (*Abstract Syntax Tree / AST*).
