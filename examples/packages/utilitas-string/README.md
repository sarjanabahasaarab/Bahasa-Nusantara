# utilitas-string

Paket utilitas manipulasi teks dan string untuk bahasa pemrograman NUSANTARA.

## Instalasi
```bash
nusantara paket pasang utilitas-string
```

## Penggunaan
```nusantara
program ContohString
gunakan "utilitas-string" sebagai us

mulai
    teksKutip : teks = us.bungkus_kutip("Merdeka")
    tampilkan("Hasil:", teksKutip)
selesai
```
