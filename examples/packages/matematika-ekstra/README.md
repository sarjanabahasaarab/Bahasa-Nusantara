# matematika-ekstra

Paket matematika tingkat lanjut untuk ekosistem bahasa pemrograman NUSANTARA.

## Instalasi
```bash
nusantara paket pasang matematika-ekstra
```

## Penggunaan
```nusantara
program Hitung
gunakan "matematika-ekstra" sebagai mtk

mulai
    k : bilangan = mtk.kuadrat(8)
    tampilkan("8 kuadrat =", k)
selesai
```
