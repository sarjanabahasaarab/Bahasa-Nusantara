# Glosarium Istilah Pemrograman NUSANTARA

Daftar istilah teknis komputasi dan pemrograman beserta padanannya dalam Bahasa Indonesia yang digunakan dalam dokumentasi resmi bahasa **NUSANTARA**.

---

| Istilah Asing (Inggris) | Istilah Bahasa Indonesia | Penjelasan Singkat |
|---|---|---|
| **Abstract Syntax Tree (AST)** | Pohon Sintaksis Abstrak | Struktur data pohon bertingkat yang merepresentasikan susunan logika kode sumber program. |
| **Assignment** | Penugasan | Operasi memberikan atau mengganti nilai ke dalam sebuah variabel menggunakan operator `=`. |
| **Boolean** | Logika | Tipe data kebenaran yang hanya memiliki dua kemungkinan nilai: `benar` (*true*) atau `salah` (*false*). |
| **Break** | Hentikan | Perintah kontrol alur untuk menghentikan perulangan sebelum kondisi berakhir. |
| **Case-sensitive** | Peka Huruf Besar-Kecil | Sifat pembeda yang memperlakukan huruf besar dan huruf kecil sebagai simbol berbeda. |
| **Compiler** | Kompilator | Program yang menerjemahkan kode sumber menjadi biner mesin atau representasi perantara. |
| **Constant** | Tetap / Konstanta | Nilai yang didefinisikan satu kali dan dilarang diubah sepanjang eksekusi program. |
| **Continue** | Lanjutkan | Perintah kontrol alur untuk melompati iterasi saat ini menuju iterasi perulangan berikutnya. |
| **Escape Sequence** | Urutan Karakter Lolos | Kombinasi karakter yang diawali tanda `\` untuk menulis karakter khusus (seperti baris baru `\n`). |
| **Function** | Fungsi | Blok subrutin modular yang dapat menerima parameter dan mengembalikan nilai. |
| **Identifier** | Pengidentifikasi | Nama unik yang diberikan untuk variabel, fungsi, konstanta, atau program. |
| **Immutable** | Tak Terubahkan / Kekal | Sifat data atau wadah yang nilainya tidak dapat dimodifikasi setelah diciptakan. |
| **Interpreter** | Penerjemah Langsung | Program yang membaca dan mengeksekusi instruksi kode secara langsung tanpa kompilasi awal ke berkas biner. |
| **Keyword** | Kata Kunci | Kata leksikal yang dicadangkan oleh tata bahasa pemrograman dan memiliki arti khusus. |
| **Lexer (Tokenizer)** | Penganalisis Leksikal | Komponen kompilator yang membaca teks sumber dan membaginya menjadi token-token leksikal. |
| **Literal** | Nilai Literal | Nilai konstan pasti yang ditulis langsung di dalam kode sumber (misal: `"Halo"`, `42`). |
| **Looping** | Perulangan | Mekanisme menjalankan sekumpulan instruksi secara berulang-ulang (`untuk`, `selama`). |
| **Mutable** | Dapat Diubah | Sifat variabel yang nilainya bebas ditugaskan ulang sepanjang program berjalan. |
| **Null / Void** | Kosong | Penanda ketiadaan nilai atau nilai hampa. |
| **Operator Precedence** | Prioritas / Presedensi Operator | Aturan urutan evaluasi antar-operator dalam ekspresi gabungan. |
| **Parser** | Penganalisis Sintaksis | Komponen kompilator yang memeriksa kepatuhan tata bahasa token dan membentuk AST. |
| **Return** | Kembalikan | Mengirimkan nilai hasil kalkulasi fungsi kembali ke titik pemanggil. |
| **Scope** | Cakupan Lingkup | Batas jangkauan wilayah kode tempat sebuah variabel atau fungsi dapat diakses. |
| **Short-circuit Evaluation** | Evaluasi Hubung Singkat | Penghentian evaluasi ekspresi logika jika hasil akhir sudah dapat dipastikan dari operan pertama. |
| **Statement** | Pernyataan | Sebuah unit instruksi lengkap yang dieksekusi oleh program komputer. |
| **Variable** | Variabel | Wadah penyimpanan data dalam memori yang nilainya dapat dimutasi. |
