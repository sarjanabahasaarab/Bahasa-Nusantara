# Menulis Program Pertama: "Halo Dunia!"

Program pertama yang lazim ditulis saat mempelajari bahasa pemrograman baru adalah mencetak teks sapaan ke layar monitor.

---

## 1. Kode Program Sapaan

Buka berkas `halo.nusantara` di penyunting teks Anda, lalu ketikkan kode berikut:

```nusantara
program Halo

mulai
    tampilkan("Halo Dunia!")
selesai
```

*(Catatan: Contoh ini menunjukkan rancangan sintaks resmi bahasa NUSANTARA dan belum dapat dijalankan sebelum alat eksekusi NUSANTARA tersedia pada fase kompilator berikutnya).*

---

## 2. Bedah Baris Program

Mari kita telaah baris demi baris:

1. **`program Halo`**
   - Mendeklarasikan bahwa unit kode ini bernama program `Halo`.
   - Kata kunci `program` wajib ditulis di baris instruksi pertama.
2. **`mulai`**
   - Menandai titik awal blok instruksi utama yang akan dieksekusi.
3. **`tampilkan("Halo Dunia!")`**
   - Memanggil fungsi bawaan `tampilkan` untuk mencetak tulisan ke keluaran terminal standar.
   - Teks yang ingin dicetak diapit oleh tanda kutip ganda (`"..."`).
4. **`selesai`**
   - Menandai akhir dari blok instruksi program utama. Setiap blok `mulai` wajib memiliki penutup `selesai`.
